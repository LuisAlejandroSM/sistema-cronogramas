RESUMEN RÁPIDO DE INSTALACIÓN (3 PASOS):
--------------------------------------------------------------------------------

1. INSTALAR POSTGRESQL (16 o 17):
   - Descargar e instalar PostgreSQL para Windows desde postgresql.org
   - Abrir pgAdmin 4 y crear una base de datos vacía llamada: "cronogramas"
   - En el Query Tool de pgAdmin, abrir y ejecutar el archivo:
     migracion\inicializar_completo.sql
     (Esto crea las tablas, los usuarios iniciales y los 16 formularios).

2. ASISTENTE AUTOMATIZADO DE PREPARACIÓN:
   - Hacer clic derecho en el archivo:
     scripts\preparar-servidor.bat -> "Ejecutar como Administrador"
   - El script solicitará la contraseña de PostgreSQL (ej: 1234), instalará
     el runtime Bun, compilará la aplicación y abrirá el puerto 3000 en el Firewall.

3. INICIAR EL SERVIDOR:
   - Para encenderlo manualmente:
     scripts\iniciar-produccion.bat
   - Para que arranque solo con Windows (24/7):
     scripts\configurar-inicio-automatico.bat (Opción 1: Tarea Programada).

--------------------------------------------------------------------------------
ACCESO AL SISTEMA Y CREDENCIALES:
--------------------------------------------------------------------------------
- URL de acceso en red local: http://<IP_DEL_SERVIDOR>:3000
- Usuario Administrador:      admin@cronogramas.local
- Contraseña por defecto:    admin1234

--------------------------------------------------------------------------------
RESPALDOS AUTOMÁTICOS:
--------------------------------------------------------------------------------
- Para respaldar la base de datos y todas las fotos/firmas en un solo clic:
  scripts\respaldar-sistema.bat
